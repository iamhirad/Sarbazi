# جزوهٔ ساختار و زبان کامپیوتر

خروجی نهایی: `../CSL_Jozveh_Persian.pdf`

ساخت دوباره (نیاز به Python 3، pypdf و Playwright/Chromium):

```
cd jozveh && python3 build.py
```

- `src/*.html`: متن فصل‌ها (به ترتیب نام فایل)
- `figs.py`: شکل‌های SVG
- `style.css`: قالب صفحه (A4، راست‌به‌چپ، فونت وزیرمتن)
